# LeetCode Solutions

My personal collection of LeetCode solutions, documenting my progress in data structures, algorithms, and problem-solving.

## Goals

- Build a consistent problem-solving habit.
- Improve my understanding of data structures and algorithms.
- Write clear, efficient solutions and revisit problems to improve them.

## Repository Structure

Accepted solutions will be stored in the `solutions/` directory once synchronisation is configured. Each solution uses the file extension of its programming language.

## Synchronisation

This repository is intended to use GitHub Actions to import previous accepted LeetCode solutions and periodically sync new ones.

## Learning Approach

For each problem, I aim to understand the reasoning behind the solution, consider alternative approaches, and will try to evaluate time and space complexity.

## Note

These solutions are shared for learning and reference. Try solving each problem independently before reviewing a solution.
